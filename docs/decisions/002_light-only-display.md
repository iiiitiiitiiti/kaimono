## 002. 表示は明るい色だけにする

- 日付: 2026-11-05
- 対象: `src/App.tsx`・`src/styles.css`・`index.html`（上の切り替えボタン・暗い色の定義・起動前に色を当てる `theme.js`）

### 決定

暗い表示への切り替えボタンを外し、暗い色の定義もまとめて消した。端末の暗い表示の設定にも合わせない。ユーザーが「ダークモードに切り替える機能いらないかも」と言い、使う場面が無かったため。

### 背景

それまでは上のボタンで明るい表示と暗い表示を切り替え、選んだ方を端末に覚えていた。端末の設定は見ていなかった。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| ボタンだけ外し、端末の暗い表示の設定に自動で合わせる | 頼まれていない動きが増える。夜に iPhone が暗い設定だと、ユーザーの知らないうちに暗くなる |
| ボタンを外し、暗い色の定義は残す | 使われない色を直し続けることになる。戻すときは git の履歴（5c97f66 より前）から戻せる |

### 影響

- 前に暗い表示を選んでいた端末も、次に開いたときから明るい表示になる。端末に残った選択（`kaimono:theme`）は読まないだけで消していない。
- 暗い表示を戻したくなったら、上の2案のどちらにするかを先にユーザーへ聞く。
